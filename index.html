Built on a State-of-the-Art Stack

ChemBot leverages modern AI orchestrators, vector storage, and new standard protocols.

LangGraph

Orchestrates multi-route query fan-out and merges multiple asynchronous retrieval branches.

MCP

Model Context Protocol

Exposes tools via openFDA and PubMed servers with isolated, standardized JSON-RPC schemas.

ChromaDB

Local vector store caching prior queries and regulatory definitions to cut external API roundtrips.

Embeddings

Uses Sentence Transformers locally to generate dense vectors for semantically indexing evidence.

OpenAI GPT-4

Acts as the reasoning model for routing decisions and outputs answer fusion based purely on evidence.

Multi-Branch Routing Pipeline

Click on any node in the execution graph to see detailed information on what it does.

User Query Input

Receives natural language clinical or pharmacological queries.

LangGraph Router

Determines routing requirements and dynamically selects database branches.

MCP Servers (openFDA / PubMed)

Spawns stdio servers, mapping parameters to API search requests.

Evidence Fusion Node

Aggregates retrieved labels, side effects, and academic abstracts.

LLM Answer Generation

Generates final answers strictly utilizing retrieved evidence context.

User Query Input

The entrypoint to the application. ChemBot accepts any free-form biomedical question from the terminal. The framework leverages vector indexes to check if the question context is already partiallycached, avoiding unnecessary downstream queries when possible.

  • Standard standard terminal read-eval-print loop
  • Optional debug levels for tracing raw HTTP and JSON-RPC

Connected Evidence Databases

ChemBot queries official, highly specific data using Model Context Protocol Servers.

FDA Drug Labels

Accesses official prescribing information, warnings, ingredients, dosage instructions, and active contraindications straight from regulatory databases.

Tool: search_drug_labels
Endpoint: api.fda.gov/drug/label

FDA Adverse Events (FAERS)

Queries millions of self-reported adverse clinical events and product problems submitted to the FDA, yielding active post-market surveillance statistics.

Tool: search_adverse_events
Endpoint: api.fda.gov/drug/event

NCBI PubMed Literature

Retrieves academic, peer-reviewed biomedical literature abstracts, clinical trials, meta-analyses, and systematic reviews via the NCBI Entrez API.

Tool: search_pubmed, fetch_abstracts
Endpoint: eutils.ncbi.nlm.nih.gov

Getting Started

Set up and launch the ChemBot command line interface locally in minutes.

1

Clone the Repository

Get the latest version of ChemBot code and submodules directly from GitHub.

2

Install Dependencies

Configure packages with pip or your favorite Python environment manager.

3

Configure Keys & Run

Set your OpenAI key and run the CLI. ChemBot automatically provisions the MCP servers.

Terminal — Installation
# Clone and enter the repository git clone https://github.com/IshaanSD/ChemBot.git cd ChemBot # Install requirements pip install -r requirements.txt # Export credentials export OPENAI_API_KEY="your-openai-api-key" export NCBI_EMAIL="your-email@example.com" # Run ChemBot CLI python -m chembot.graph_cli --chroma_dir ./chroma_db
